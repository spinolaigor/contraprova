# Roadmap público — Contraprova

## Concluído
- Interface brutalista responsiva no GitHub Pages.
- Exportador de dados auditados e proteção contra inclusão de demonstrações.
- Catálogo de fontes, política de publicação, registro de decisões.
- Monitoramento inicial de metadados de três páginas fixas.
- Licença MIT para código próprio e dedicação CC0 para dados próprios explicitamente definidos.

## Fase 1 — Integridade (em andamento)
- [ ] Confirmar execução real do workflow de monitoramento e registrar resultados.
- [ ] Migrar testes e módulos úteis do protótipo v0.3, sem sobrescrever o dashboard atual.
- [ ] Validar rigorosamente o esquema das verificações, incluindo origem e revisão.
- [ ] Criar registro público de correções e política de versões.
- [ ] Validar URLs, permissões de coleta, limites e tratamento de erros.

## Fase 2 — Descoberta
- [ ] Conectores RSS/Atom, sitemap e JSON-LD ClaimReview por fonte.
- [ ] Deduplicação por URL canônica, título e identidade de afirmação.
- [ ] Fila de revisão com metadados, evidências e status explícitos.
- [ ] Relatórios de cobertura e falhas de coleta.
- [ ] Nunca publicar vereditos sem auditoria.

## Fase 3 — Auditoria e escala
- [ ] Lote piloto de 20 afirmações reais com documentação.
- [ ] Evidências primárias e minutagem de vídeos quando disponíveis.
- [ ] Divergências entre fontes sem consenso artificial.
- [ ] Revisão humana, histórico de correções e links permanentes.

## Fase 4 — Visualização
- [ ] Distribuições por fonte, evento e assunto com denominadores claros.
- [ ] Exportações CSV e JSON com metadados e data de corte.
- [ ] Visão pública de cobertura, separada dos vereditos.
- [ ] Descrições acessíveis para gráficos e formatos compartilháveis.

## Fase 5 — Colaboração pública
- [ ] Formulário sem cadastro, com antispam e moderação.
- [ ] Propostas de correção sempre vinculadas a evidências.
- [ ] Sem votação popular sobre o que é verdade.
