# Contraprova — estado da publicação

Repositório oficial do projeto Contraprova.

## Versão preparada

O pacote local v0.3 (coleta contínua) contém aplicação HTML/CSS/JS, bases demonstrativas, catálogo de fontes, documentação, testes Python e workflows GitHub Actions.

## Regras editoriais

- Afirmações e verificações são entidades distintas.
- A mesma afirmação pode ter vários vereditos de fontes diferentes.
- Registros demonstrativos não são fatos auditados.
- Divergências e revisões devem ser preservadas.
- Coleta automatizada identifica novidades, mas não publica vereditos definitivos sem revisão.
- O público poderá consultar fontes e propor correções com evidências, sem votar na verdade.

## Publicação

Este documento registra o início da publicação. Os demais arquivos da v0.3 ainda precisam ser importados e validados antes da ativação da coleta contínua e do GitHub Pages.
