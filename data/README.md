# Dados do Contraprova

## Dedicação dos dados próprios

Os dados estruturados originais que os contribuidores têm o direito de disponibilizar em `data/publicados.json` são oferecidos sob **Creative Commons CC0 1.0 Universal**: https://creativecommons.org/publicdomain/zero/1.0/

A dedicação CC0 não se aplica a textos, vídeos, fotografias, marcas, artigos ou conjuntos de dados de terceiros, mesmo quando citados, vinculados ou referenciados. As respectivas licenças e direitos permanecem em vigor. A legislação aplicável pode impor outras limitações.

**Importante:** o diretório `data/` também pode conter metadados de fontes externas, registros de monitoramento e material demonstrativo. A dedicação CC0 abrange apenas contribuições originais sob controle dos contribuidores; não é uma declaração de propriedade sobre todo o conteúdo desse diretório.

## Arquivos

- `publicados.json`: dados auditados e aprovados para o dashboard.
- `auditoria/registros.json`: registros em avaliação, não necessariamente publicáveis.
- `monitoramento/descobertas.json`: alterações de páginas observadas, sem vereditos.
- `monitoramento/fontes.json`: configuração de fontes a monitorar.

Sempre preserve links e metadados de origem para permitir verificação, mesmo quando a licença não exige atribuição.
